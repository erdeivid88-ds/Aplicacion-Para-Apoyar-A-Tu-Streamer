# Contribuir

Usa Node.js 22 LTS, crea una rama, ejecuta `npm run lint`, `npm run typecheck`, `npm test` y `npm run build` y abre un pull request. No incluyas credenciales ni implementes automatización de chat, cookies o audiencia artificial.

## Versionado

Cada cambio destinado a una nueva build debe actualizar la versión siguiendo SemVer:

- **PATCH** para correcciones, arreglos visuales, mejoras responsive y cambios pequeños.
- **MINOR** para funcionalidades nuevas compatibles con versiones anteriores.
- **MAJOR** para cambios incompatibles.

Nunca se reutiliza una versión que ya haya generado o publicado artefactos finales.
